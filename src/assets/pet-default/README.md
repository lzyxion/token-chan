# 내장 기본 캐릭터 이미지 (pet-default)

이 폴더의 상태명 이미지가 빌드에 번들되어 **기본 캐릭터**가 된다.
캐릭터를 그리는 방법은 이미지 팩 하나뿐이라 — 코드로 그리는 폴백은 없다 —
**이 폴더가 비면 캐릭터가 아무것도 뜨지 않는다.** 최소한 `idle` 한 장은 있어야 한다.
사용자 팩(설정의 캐릭터 팩/모델 규칙)이 있으면 그쪽이 우선.

현재 기본 팩은 **토큰짱** PNG 8장. 다른 캐릭터로 바꾸려면 **같은 파일명으로 그림만 교체**하면 되고,
코드는 건드릴 필요가 없다.

## 8장은 같은 캔버스로 굽는다 (`scripts/build-default-pack.mjs`)

펫은 캐릭터를 고정 상자(`.cat` 104×96)에 `object-fit: contain` 으로 넣는다. 그래서 장마다
캔버스 크기가 다르면 **장마다 다른 배율로 늘어나** 상태가 바뀔 때 캐릭터 크기가 들쭉날쭉해진다.
원본 그림(여백이 제각각인 상태)에서 다음처럼 구우면 그 문제가 사라진다:

```
node scripts/build-default-pack.mjs <원본폴더> [긴변px]   # 기본 640
```

- 불투명 영역만 남기고 원본 여백은 버린다 (여백 크기가 장마다 달라 기준이 못 된다)
- 배율은 **8장 공통** — 장마다 맞추면 누운 그림이 선 그림만큼 커진다
- 캔버스는 가장 큰 내용에 맞춘 하나, 각 장은 **하단 중앙**(발이 바닥에 닿게)

긴 변 640px 인 이유: 펫이 화면에 그려지는 최대 크기가 104×96 CSS px × 배율 250% ≈ 260px 이고,
HiDPI 2배를 쳐도 520px 이다. 그 이상은 용량만 늘고 보이지 않는다.

지원 형식과 우선순위는 저장소 루트 README의 "지원 이미지 형식" 표를 따른다.

## 파일 규칙

| 파일 | 상태 | 필수 |
|---|---|---|
| `idle.(svg\|png\|webp\|gif\|apng)` | 대기 | ✅ (없으면 캐릭터가 안 뜸) |
| `working.*` | 작업 중 | 선택 — 없으면 idle |
| `alert.*` | 한도 경고 | 선택 |
| `sleep.*` | 잠 | 선택 |
| `exhausted.*` | 소진 | 선택 |
| `refreshed.*` | 블록 초기화 | 선택 |
| `done.*` | 작업 완료 | 선택 |
| `poke.*` | 클릭 | 선택 |

- **투명 배경 필수**, 발이 이미지 **하단 중앙**에 닿게 (창 자동 맞춤 기준)
- 권장 크기: 래스터는 긴 변 512px 이상(배율 250%에서도 선명), 여백 최소. SVG는 무관
- 정적 이미지여도 상태 모션(숨쉬기·흔들림·폴짝)은 앱이 CSS로 얹어 준다
- 소진율은 **상태 단위**로만 표현된다. 연속 변화 중 그림에 얹히는 건 호흡 속도와 땀방울뿐

## 캐릭터를 교체할 때

8종을 **같은 캐릭터로 일관되게** 뽑는 게 핵심이다. AI 생성기를 쓴다면 한 세션에서
캐릭터 시트로 한 번에 뽑거나, 같은 시드·같은 베이스 프롬프트를 유지할 것.
상태별로 달라져야 하는 건 표정·자세·색조뿐이고, 캐릭터 자체는 동일해야 한다.

상태별 연출 의도:

| 상태 | 의도 |
|---|---|
| `idle` | 평상시. 나머지 6종의 기준이 되는 포즈 |
| `working` | 작업 중. 집중한 표정 |
| `alert` | 한도 경고. 긴장·초조, 경고색(붉은 계열)으로 |
| `sleep` | 무활동. 눈 감음, 차분한 색조 |
| `exhausted` | 한도 소진. 탈진, 무채색 |
| `refreshed` | 블록 초기화 직후. 밝고 생기 있게 |
| `done` | 세션 작업 완료 직후. 해냈다는 뿌듯함 — 기본 팩은 **윙크**로 `refreshed`(∪∪ 눈)와 갈랐다. 둘 다 기쁜 얼굴이라 표정이 겹치면 무엇이 끝난 건지 구분이 안 된다 |
| `poke` | 클릭. 살짝 놀라거나 반가운 표정 |

앱이 소품 배지(`z` `!` `🪫` `✨` `🎉` `💦`)와 모션(숨쉬기·흔들림·폴짝)을 그림 위에 얹으므로,
그림 안에 같은 요소를 그려 넣으면 중복된다.
