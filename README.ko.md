# 토큰쨩 (TokenChan)

AI CLI의 **토큰 사용량·한도·작업 상태**를 바탕화면 위 캐릭터로 보여주는 데스크톱 펫입니다.

**Claude Code · Codex CLI · Antigravity CLI**를 지원합니다. 작업이 끝나거나 컨텍스트와 사용 한도가 위험해지면 캐릭터와 말풍선으로 알려줍니다.

## 주요 기능

- **작업 상태 감지** — CLI가 작업 중인지, 방금 끝났는지 캐릭터 상태로 보여줍니다.
- **사용량 게이지** — 컨텍스트와 공식 사용 한도, 리셋까지 남은 시간을 바로 확인합니다.
- **통합 사용량 패널** — 오늘 사용량, 기간별 통계, 모델 구성비와 최근 세션을 모아 봅니다.
- **상태 알림** — 작업 완료, 한도 위험·소진·초기화, 장시간 미사용 상태를 말풍선으로 알려줍니다.
- **캐릭터 커스터마이징** — 상태별 이미지와 대사를 바꾸고 모델마다 다른 캐릭터를 연결할 수 있습니다.
- **다중 계정 집계** — 이 컴퓨터에서 발견한 CLI 계정을 선택해 함께 집계합니다.

별도의 토큰쨩 계정이나 로그인은 필요하지 않습니다. 이미 로그인되어 있는 CLI의 기록과 설정을 사용합니다.

## 설치

[GitHub Releases](https://github.com/lzyxion/token-chan/releases)에서 운영체제에 맞는 파일을 받습니다.

| 운영체제 | 배포 형식 | 지원 상태 |
| --- | --- | --- |
| Windows | `.msi` | 설치 파일 제공 |
| macOS | `.dmg` | 설치 파일 제공 |
| Linux | 소스 빌드 | 설치 파일 미제공 |

> [!WARNING]
> 현재 배포 파일에는 코드 서명이 없습니다.
> **Windows**에서는 SmartScreen의 `추가 정보 → 실행`, **macOS**에서는 앱을 우클릭한 뒤 `열기`를 선택하세요.

토큰쨩을 실행하기 전에 사용하려는 Claude Code, Codex CLI 또는 Antigravity CLI가 설치되어 있고 로그인되어 있어야 합니다.

## 빠른 사용법

| 동작 | 결과 |
| --- | --- |
| 클릭 | 캐릭터가 반응하며 현재 사용량을 말풍선으로 알려줍니다. |
| 더블클릭 | 사용량 패널을 열거나 닫습니다. |
| 드래그 | 캐릭터를 옮기고 놓은 위치를 기억합니다. |
| 게이지 로고 클릭 | 자동 선택 또는 Claude, Codex, Antigravity 중 하나로 게이지를 고정합니다. |
| 우클릭 | 숨기기, 패널, 계정, 캐릭터 스튜디오와 설정 메뉴를 엽니다. |
| 트레이 아이콘 | 펫 메뉴를 엽니다. 클릭 통과 모드를 끌 때도 사용합니다. |

## 캐릭터가 알려주는 상태

| 상태 | 조건 |
| --- | --- |
| 평상시 | 특별한 이벤트가 없을 때 |
| 작업 중 | CLI가 현재 응답을 생성하고 있을 때 |
| 작업 완료 | 세션의 작업 하나가 끝났을 때 |
| 경고 | 컨텍스트나 공식 한도가 위험 기준값을 넘었을 때 — 기본 80% |
| 소진 | 세션 한도가 100%에 도달했을 때 |
| 초기화 | 새로운 한도 블록이 열렸을 때 |
| 잠 | 설정한 시간 동안 활동이 없을 때 — 기본 30분 |
| 클릭 | 캐릭터를 클릭했을 때 |

상태가 바뀌면 해당 캐릭터 이미지와 대사가 함께 나타납니다. 한도 리셋이 가까워지면 상태와 관계없이 미리 알려줍니다. 기본 알림 시점은 리셋 15분 전입니다.

## 게이지 읽기

캐릭터 옆의 링은 현재 선택된 서비스 하나의 값입니다. 맨 위 로고가 보고 있는 서비스이며, 작업 중에는 로고가 깜빡입니다.

| 기본 상태 | 마우스를 올렸을 때 |
| :---: | :---: |
| <img src="docs/demo/no-hover.png" alt="서비스 로고와 사용량 링만 표시된 토큰쨩 게이지의 기본 상태" width="280" /> | <img src="docs/demo/hover.png" alt="모델, 컨텍스트 사용량, 공식 한도와 리셋 시간이 펼쳐진 토큰쨩 게이지" width="280" /> |

- 자동 모드에서는 `작업 중 → 마지막으로 사용한 세션 → 오늘 사용량 1위` 순서로 서비스를 선택합니다.
- 로고를 클릭하거나 `설정 → 일반 → 게이지`에서 표시할 서비스를 고정할 수 있습니다.
- 점선 링은 0%가 아니라 **아직 값을 알 수 없음**을 뜻합니다.
- 라벨은 `마우스를 올렸을 때`, `작업 중에는 계속`, `항상` 중 하나로 설정할 수 있습니다.
- 작업 중에는 `Claude · opus-5 · 4분 12초`처럼 현재 작업의 경과 시간을 표시합니다.

서비스별 값을 한꺼번에 비교하려면 사용량 패널을 사용하세요.

## 캐릭터 커스터마이징

`설정 → 캐릭터 → 캐릭터 스튜디오 열기`에서 캐릭터를 만들고 상태별 이미지와 대사를 편집할 수 있습니다. 이미지를 상태 카드에 끌어다 놓아 등록하고, `▶ 테스트`로 실제 동작을 확인합니다.

<p align="center">
  <img src="docs/demo/character-studio.png" alt="캐릭터의 상태별 이미지와 대사를 편집하고 테스트하는 캐릭터 스튜디오" width="720" />
</p>

캐릭터 팩은 다음 구조로 저장됩니다.

```text
<설정 폴더>/token-chan/characters/
└─ my-cat/
   ├─ idle.gif        # 필수 — 다른 상태 이미지가 없으면 idle로 대체
   ├─ working.gif
   ├─ alert.gif
   ├─ sleep.gif
   ├─ exhausted.gif
   ├─ refreshed.gif
   ├─ done.gif
   ├─ poke.gif
   ├─ speech.json     # 선택 — 캐릭터 대사
   └─ pack.json       # 선택 — 사용하지 않을 상태 목록
```

- 지원 형식: `.gif`, `.webp`, `.apng`, `.png`, `.svg`
- 파일당 최대 크기: 20MB
- 투명 배경과 긴 변 512px 이상을 권장합니다.
- 모든 상태 이미지를 같은 캔버스와 배율로 만들면 상태 전환 시 크기가 흔들리지 않습니다.
- 숨쉬기, 흔들림, 폴짝 모션과 `z`, `!`, `🪫`, `✨` 배지는 앱이 이미지 위에 추가합니다.
- 캐릭터 폴더를 통째로 복사하면 이미지, 대사와 상태 구성을 함께 공유할 수 있습니다.

### 대사 만들기

대사는 캐릭터 폴더의 `speech.json`에 저장됩니다.

```json
{
  "enter.working": ["코딩 시작!|화이팅", "일하러 가자~"],
  "poke": ["오늘 {오늘토큰} 썼어"]
}
```

- 한 상황에 여러 대사를 넣으면 그중 하나를 무작위로 사용합니다.
- `|`는 말풍선 안에서 줄을 바꿉니다.
- `{오늘토큰}`, `{세션}`, `{컨텍스트}`, `{리셋}`, `{모델}`, `{벤더}` 등의 변수는 표시 시점의 값으로 바뀝니다.
- 값을 알 수 없는 변수가 포함된 대사는 표시하지 않습니다.

### 모델별 캐릭터

`설정 → 캐릭터 → 모델별 캐릭터 규칙`에서 모델 접두사와 캐릭터를 연결할 수 있습니다.

예를 들어 `claude`는 모든 Claude 모델에, `claude-opus`는 Opus 모델에만 적용됩니다. 여러 규칙이 일치하면 더 긴 접두사를 우선합니다.

## 데이터와 개인정보

- 토큰과 세션 통계는 이 컴퓨터에 저장된 CLI의 세션 기록에서 계산합니다.
- 대화 내용이나 사용 통계를 토큰쨩의 별도 서버로 업로드하지 않습니다.
- Claude와 Codex의 공식 사용 한도를 갱신하기 위해 각 서비스의 사용량 API에 읽기 전용 요청을 보냅니다.
- 이 요청에는 기존 CLI가 로컬에 저장한 인증 정보를 사용합니다.
- 토큰쨩 자체 계정, 원격 데이터베이스 또는 분석용 텔레메트리는 없습니다.
- 사용자 설정과 커스텀 캐릭터는 운영체제의 설정 폴더에 저장됩니다.

CLI의 기록 형식이나 사용량 API가 변경되면 일부 값이 일시적으로 표시되지 않을 수 있습니다. Antigravity CLI는 공식 한도 정보를 제공하지 않으므로 로컬 기록에서 확인할 수 있는 값만 표시합니다.

## 소스에서 빌드

다음 도구가 필요합니다.

- Node.js 22
- pnpm
- Rust stable
- Linux에서는 Tauri 시스템 라이브러리

```sh
pnpm install
pnpm tauri dev      # 개발 모드 실행
pnpm tauri build    # 설치 패키지 생성
```

Ubuntu 계열에서는 먼저 시스템 라이브러리를 설치합니다.

```sh
sudo apt-get install -y \
  libwebkit2gtk-4.1-dev libxdo-dev libssl-dev \
  libayatana-appindicator3-dev librsvg2-dev
```

프런트엔드는 React와 TypeScript, 데스크톱 앱은 Tauri 2, 사용량 파싱과 집계는 Rust로 작성되어 있습니다.
